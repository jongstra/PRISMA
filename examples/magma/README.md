# MaGMa examples

MaGMa use case files. Load one with **Load MaGMa YAML** on the MaGMa page.

| Name | Description |
|---|---|
| [`demo.yaml`](demo.yaml) | The fictional organisation in the main README: 83 use cases: 5 business risks, 16 L2 and 62 L3. Three rules use Override; the Denial of Service score rests on two of them. Load [`../dettect/demo.yaml`](../dettect/demo.yaml) first |
| [`example.yaml`](example.yaml) | Example use cases on all three levels, for all domains |
| [`heatmap-colours.yaml`](heatmap-colours.yaml) | Fictional rules with chosen scores, so the MaGMa heatmap shows every colour in every tactic column; for checking the heatmap's look |
| [`manual_export.xlsx`](manual_export.xlsx) | Example input for [`tools/convert_manual_excel.py`](../../tools/convert_manual_excel.py) |
| [`paste-test.xlsx`](paste-test.xlsx) | Rows to copy and paste into the L1, L2 and L3 sheets, to try pasting from a spreadsheet; see its first sheet |
| [`template.yaml`](template.yaml) | The empty [MaGMa template](../../templates/), converted: the standard L1 and L2 use cases |

# Frontend

The PRISMA web application (Vue 3, Pinia, Vite). It runs entirely in the browser. Its font, Inter, comes with the app (package `@fontsource/inter`, SIL Open Font License), so it looks the same on every computer.

| Name | Description |
|---|---|
| [`e2e/`](e2e/) | Browser smoke tests (`npm run test-e2e`) |
| [`public/`](public/) | The ATT&CK catalog, generated by [`tools/build_attack_catalog.ipynb`](../tools/build_attack_catalog.ipynb) (don't edit by hand), and MITRE's licence for it (`LICENCE-ATTACK.txt`) |
| [`src/`](src/) | Source code of the application |
| [`.prettierrc.json`](.prettierrc.json) | Code formatting settings (`npm run format`) |
| [`env.d.ts`](env.d.ts) | TypeScript types for Vite |
| [`eslint.config.js`](eslint.config.js) | Code check settings (`npm run lint`) |
| [`index.html`](index.html) | The page the application starts from |
| [`package-lock.json`](package-lock.json) | Exact versions of all dependencies |
| [`package.json`](package.json) | Dependencies and npm scripts |
| [`playwright.config.ts`](playwright.config.ts) | Browser smoke test settings |
| [`tsconfig.app.json`](tsconfig.app.json) | TypeScript settings for the application |
| [`tsconfig.json`](tsconfig.json) | TypeScript settings, combining the other three and the one in `e2e/` |
| [`tsconfig.node.json`](tsconfig.node.json) | TypeScript settings for the configuration files |
| [`tsconfig.vitest.json`](tsconfig.vitest.json) | TypeScript settings for the unit tests |
| [`vite.config.ts`](vite.config.ts) | Build and development server settings |
| [`vitest.config.ts`](vitest.config.ts) | Unit test settings |

## Commands

```sh
npm ci              # install the dependencies
npm run dev         # run the app at http://localhost:5173
npx vitest run      # run the unit tests
npm run test-e2e    # build the app and run the browser smoke tests in Chrome
npm run build       # build the app into dist/
npm run type-check  # check the types
npm run lint        # check the code for common mistakes
npm run format      # format the code
```

## Tests

- **Unit tests** (`src/**/__tests__/`, Vitest): the calculations, the file checks and the components, each on its own. They run in a few seconds and need no browser.
- **Browser smoke tests** (`e2e/`, Playwright): the built app in your installed Chrome, without a window. They check that the pages open, that DeTT&CT and MaGMa files load, and that a saved MaGMa file keeps what was entered. They fail on any error in the browser console. After a failure, `npx playwright show-trace test-results/<test>/trace.zip` replays the test step by step.
